Privacy Policy

Last updated: April 27, 2026

1. Introduction

Mr Martin ("the App", "we", "us") is a desktop application that allows content creators to automate video production and publish videos directly to their own TikTok profiles. This Privacy Policy explains what information the App accesses, how it is used, and how it is protected for each user.

2. Who We Are

Mr Martin is a content creation tool available to independent content creators and social media professionals. Users authenticate with their own TikTok account to publish content they own. The App does not operate or manage TikTok accounts on behalf of the developer.

3. Information the App Accesses

When a user connects their TikTok account, the App accesses the following data through the TikTok API, solely on behalf of that authenticated user:

  • Basic profile information (open_id, display name, avatar URL) — used to identify the connected account within the App interface.
  • OAuth access and refresh tokens — used to authenticate API requests on behalf of the user. Stored locally on the user's own device.
  • Creator account settings (privacy level options, interaction preferences) — queried before each post to ensure compliance with the user's account settings.
  • Published video metadata (titles, view counts, like counts, share counts, comment counts) — accessed via the Video Query API to display performance analytics to the authenticated user within the App only.
  • Account statistics (follower count, following count, total likes, video count) — displayed to the authenticated user for content performance monitoring.

4. How We Use This Information

All data accessed through the TikTok API is used exclusively to provide the App's features to the authenticated user:

  • Authenticate API requests using the user's OAuth tokens
  • Publish videos to the user's own TikTok profile on their behalf
  • Display the user's own video performance metrics within the App dashboard
  • Respect the user's account privacy and interaction settings when posting

The App does not display TikTok content on any public website, does not aggregate data from multiple users, and does not share any user data with third parties.

5. Data Storage

All data is stored locally on the user's own device. The App does not operate any cloud server or database. OAuth tokens, profile information, and video metadata are saved in local configuration files accessible only to the user. No personal data leaves the user's device except through direct calls to TikTok's official API endpoints.

6. Third-Party Services

The App integrates with the following third-party services to provide its functionality:

  • TikTok Login Kit — for OAuth authentication
  • TikTok Content Posting API — to publish videos to the user's profile
  • TikTok Video Query API — to retrieve the user's own video performance data for in-app analytics
  • AssemblyAI — for audio transcription (audio data is sent to their API; governed by AssemblyAI's privacy policy)
  • OpenAI — for AI-generated captions (text data is sent to their API; governed by OpenAI's privacy policy)

7. Data Retention

OAuth tokens remain on the user's device until revoked or deleted. Video files, transcripts, and captions are generated and stored locally; users may delete them at any time. The App does not retain any user data after uninstallation.

8. Your Rights

As a user of the App, you may at any time:

  • Revoke the App's access to your TikTok account via TikTok's Settings > Security > Apps and Websites
  • Delete all locally stored tokens and configuration files
  • Request deletion of any data held about you by contacting us (see Section 11)
  • Uninstall the App entirely

9. Data Security

OAuth tokens are stored in local configuration files on the user's machine. We recommend keeping your device secure and not sharing configuration files with others. The App transmits data only over HTTPS to TikTok's and third-party API endpoints.

10. Children's Privacy

The App is intended for content creators aged 18 and older. We do not knowingly collect information from minors.

11. Changes to This Policy

We may update this Privacy Policy from time to time. The updated version will be posted on this page with a revised date. Continued use of the App after changes constitutes acceptance of the updated policy.

12. Contact

For questions or data deletion requests regarding this Privacy Policy, please contact us via GitHub.
